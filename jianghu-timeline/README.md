# 江湖编年史 · 名剑与剑客时间轴

一幅横向展开的卷轴：名剑（剑形节点）与剑客（朱砂菱印）按朝代先后落在同一条古韵时间轴上。
零前端框架、零图表/虚拟列表库；后端只提供只读接口。

## 运行

```bash
npm start          # http://localhost:3000
npm test           # 纯函数单测 + 真实数据集成测试（共 20 项）
```

## 操作

- 拖拽 / 滚轮：平移；`Ctrl/⌘ + 滚轮`、双击、`＋/−` 按钮：缩放；方向键平移
- 缩放经过阈值时在 **朝代 → 世纪 → 单件** 三级粒度间切换，顶栏胶囊实时显示当前粒度
- 点击节点：弹出卡片 → 「查看详情」拉取 `GET /api/swords/:id`（或 swordsmen）详情
- 顶部搜索：定位名剑/剑客并剑影高亮约 2 秒；无结果时 toast 提示
- 「压测」开关：把数据复制到 2070 条，左下角实时显示渲染节点数 / 总量 / fps

## 架构

```
server.js                  只读 API（/api/swords[/:id]、/api/swordsmen[/:id]）+ 静态服务，零依赖
data/*.json                名剑 42 条、剑客 27 条
public/js/timeline-math.js 全部几何与布局的独立纯函数（可 Node 单测）
public/js/main.js          rAF 渲染循环、节点池虚拟化、交互、URL 同步
```

### 纯函数（timeline-math.js）

| 函数 | 职责 |
| --- | --- |
| `yearToWorldX` / `worldXToYear` | 刻度映射及其逆映射（可往返） |
| `worldToScreenX` / `screenToWorldX` / `zoomAt` | 相机映射、逆映射、锚点缩放 |
| `assignLanes` | 泳道分配（贪心区间划分 + 溢出聚合），保证任意两节点不重叠 |
| `findVisibleRange` | 可视区计算：**二分查找**候选区间，调用方只做小范围精确边缘判断 |
| `dynastyForYear` / `normalizeItem` | 朝代二分反查、缺失字段兜底归一化 |
| `rulerTicks` / `layoutChips` | 刻度尺生成、朝代聚合 chip 合并布局 |

### 虚拟化与动画生命周期

- 节点按 `worldX` 升序存储；每帧用 `findVisibleRange` 二分出可视窗口（含 0.8 屏缓冲），
  从元素池取/还 DOM，**渲染节点数 = O(视口)**，与数据总量无关（压测 2070→4140 条时峰值不变，见集成测试）。
- 入场墨晕 `.ink`、高亮环 `.ring` 都是节点的**子元素**，节点回收时一并离开文档，
  不存在虚拟化回收后仍残留的动画元素。
- 每帧动画（相机缓动、节点位移）只在 `requestAnimationFrame` 循环内写入缓存的元素引用。

### 泳道不重叠的保证

`assignLanes` 在该粒度的**最小缩放值**上计算泳道：粒度内继续放大，世界间距相对屏幕只会变大，
因此粒度内任意缩放值都不重叠；泳道数超上限时溢出条目按时间桶聚合为 `+N` chip（独立泳道），
点击可放大展开。朝代粒度则聚合为每代一个 chip，相邻重叠时自动合并。

### 无精确年份朝代的兜底映射（可解释）

| 朝代 | 映射区间 | 依据 |
| --- | --- | --- |
| 上古传说 | 前 3000 — 前 2071 | 传说时代无纪年，取夏之前的标称区间，仅作定位 |
| 夏 | 前 2070 — 前 1601 | 夏商周断代工程推定 |
| 商 | 前 1600 — 前 1047 | 同上；西周起于前 1046（武王克商） |

数据级兜底（`normalizeItem`，UI 以「约」标识）：

- 缺 `year` 有朝代 → 取朝代区间中点（如「青霜剑」）；
- 缺 `dynasty` 有年份 → 按年份二分反查朝代（如「掩日剑」）；
- 俱缺 → 置于纪年中点并双重标记推定；
- 上古/夏/商本身即推定朝代，节点一律带「约」。

### 边界情况处理

- **朝代缺失 / 年份缺失**：见上表，全部可解释并带「推定」标识；
- **年代区间重叠**：泳道算法保证同泳道水平间隔、跨泳道垂直错开，任意两节点不重叠；
- **压测卡顿**：节点池 + 二分可视区 + 每帧只写 transform，渲染数常数级；
- **搜索无结果**：toast「未寻得」提示；
- **佩剑找不到**：剑客未配 `swordId` 时卡片显示「佩剑 · ×××，未见于谱」（如裴旻、越女）；
- **移动端手势冲突**：`touch-action: pan-y` 让纵向滚动走原生、横向拖拽由 JS 接管，
  双指捏合缩放 + iOS `gesturestart` 拦截，另有 ＋/− 按钮兜底。

### URL 状态

`#x=<相机位移>&s=<缩放>&f=<焦点条目>` 每 250ms 写入 `location.hash`（replaceState）。
刷新或分享后恢复到同一视口；详情弹窗可一键复制 `#f=` 分享链接。
